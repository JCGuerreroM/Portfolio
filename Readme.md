## 🎨 Características del Proyecto

* **Tema Oscuro (Dark Mode):** Paleta moderna en tonos oscuros (`#0A0A0E`) con acentos vibrantes violetas/morados (`#7B2CBF`).
* **Diseño Responsive:** Adaptado a dispositivos móviles, tablets y pantallas de escritorio.
* **Sección de Proyectos (DOM):** Demostración interactiva de ejercicios desarrollados en JavaScript DOM.
* **Integración Directa:** Redirección a mi comunidad en Steam desde la sección de intereses.

## 📂 Proyectos Destacados (Ejercicios DOM)

| Proyecto | Descripción |
| :--- | :--- |
| **Dom-Carro** | Simulación / manipulación interactiva de carro con el DOM. |
| **Cursor Animado** | Efectos visuales de cursor personalizados con JS. |
| **Dom Cronómetro** | Aplicación de temporizador y cronómetro interactivo. |
| **Dom Carrusel** | Carrusel de imágenes funcional. |
| **Dom Galería** | Galería dinámica de elementos visuales. |
| **Dom Mensaje** | Interacción de eventos y mensajes dinámicos. |
| **Dom Batería** | Instrumento virtual que responde a eventos de teclado/clic. |
| **Dom Calculadora** | Calculadora funcional maquetada e interactiva. |
| **Dom Lista** | Lista de tareas / elementos dinámicos (To-Do List). |
